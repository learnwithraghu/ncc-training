# Challenge 01 - First Jenkinsfile

Create the simplest possible Jenkinsfile for a PHP project using `hello.php`.

## Where the code is

- PHP code: `07-Jenkins/challenges/challenge-01/hello.php`
- Jenkinsfile location: create your `Jenkinsfile` in `07-Jenkins/challenges/challenge-01/`

## Expected

1. Create a new Pipeline job in Jenkins UI.
2. Point it to the local cloned repo on EC2.
3. Use a Jenkinsfile from the challenge folder in `07-Jenkins/challenges/challenge-01/`.
4. Run `php hello.php` in the job.
5. Run one stage only.
6. Click **Build Now** and confirm the job runs.
