# Challenge 03 - PHP Build Stage

Create a Jenkinsfile that runs a simple PHP build step using `build.php`.

## Where the code is

- PHP code: `07-Jenkins/challenges/challenge-03/build.php`
- Jenkinsfile location: create your `Jenkinsfile` in `07-Jenkins/challenges/challenge-03/`

## Expected

1. Create a Pipeline job in Jenkins.
2. Use the repo cloned locally on EC2.
3. Add a build stage before testing.
4. Use the `build.php` file for the build step.
5. Place the Jenkinsfile in the same challenge folder.
5. Show output from the build in Jenkins console.
6. Run the job using **Build Now**.
