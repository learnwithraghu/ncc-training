# Lesson 03 - Jenkins Web UI First Steps

Open Jenkins in the browser and complete the first login flow.

## Learn

- Find the initial admin password
- Unlock Jenkins
- Install suggested plugins
- Create the first admin user

## Practice

```bash
sudo cat /var/lib/jenkins/secrets/initialAdminPassword
```

Then open:

```text
http://<EC2-PUBLIC-IP>:8080
```

## Checkpoint

Did you reach the Jenkins dashboard successfully?
