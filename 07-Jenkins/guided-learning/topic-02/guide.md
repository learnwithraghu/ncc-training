# Topic 2: Jenkins UI Overview

**Time:** 20 minutes

## Goal

Log in to Jenkins and explore the main areas of the web interface.

## Commands to Use

No terminal commands required.

## Guided Steps

1. Open the Jenkins URL in your browser.
2. Log in with your username and password.
3. Identify the main menu: New Item, People, Build History, Manage Jenkins.
4. Go to **Manage Jenkins → Plugins → Installed plugins** and verify Git, Pipeline, and Gitea plugins are present.
5. Go to **Manage Jenkins → Credentials** and view the global credential store.

## Checkpoint

What is the difference between a plugin and a credential?
