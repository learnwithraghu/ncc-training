# Topic 9: Jenkins Features

**Time:** 20 minutes

## Goal

Explore build history, artifacts, parameters, and replay.

## Commands to Use

No new terminal commands.

## Guided Steps

1. Open the `gitea-pipeline` job and view the **Build History**.
2. Open a build and download an artifact.
3. Add a string parameter named `GREETING` to the job.
4. Update the pipeline to use `params.GREETING`.
5. Use **Replay** to test a small pipeline change.

## Checkpoint

When is **Replay** more useful than editing the job configuration?
