# Guided Learning - Python Boto3

This learning path uses AWS CloudShell and one self-contained lesson per topic.

## Structure

- `topic-01/` through `topic-05/` contain the guided lessons
- each topic has a `guide.md`
- each topic takes about 20 minutes
- the module-level `challenge.md` provides final independent practice

## Recommended Flow

1. Open AWS CloudShell.
2. Confirm the current identity and Region.
3. Open the topic guide and type the example script.
4. Run the script and inspect the result.
5. Complete the checkpoint before continuing.
6. Remove any resources created during practice.

## Topic List

- Topic 01 - Boto3 Setup, Sessions, and Clients
- Topic 02 - Calling AWS APIs and Reading Responses
- Topic 03 - Parameters, Collections, and Resource Actions
- Topic 04 - Errors, Paginators, and Waiters
- Topic 05 - Building a Multi-Service Automation Script

## Important

Boto3 sends real requests to the AWS account. A successful Python command can create, change, or delete real resources. Read each operation name and its parameters before running it.
